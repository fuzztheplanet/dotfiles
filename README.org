#+TITLE: My Dotfiles
#+OPTIONS: toc:nil num:nil

Hello, and welcome to my /dotfiles/: the configuration files I carry from
machine to machine mostly aimed for ArchLinux desktops, laptops or VMs. Most of
the ideas here were stolen^Wborrowed from other people's setups. Please feel
free to borrow back :)

*Warning:* this repository is a constant work-in-progress. Some configuration
files might not work out-of-the-box and/or are poorly documented. You have been
warned!

* Getting started

The =manage.sh= script does the plumbing. It reads a /profile/ (a small shell
file under =profiles/=) which declares one /module/ per tool, and for each
module knows which packages to install and which files to symlink where. The
commands are =list=, =install= / =uninstall= for packages, and =deploy= /
=remove= for the symlinks; =all= selects every module.

#+begin_src shell
$ git clone https://github.com/fuzztheplanet/dotfiles ~/.dotfiles
$ cd ~/.dotfiles
$ ./manage.sh help
$ ./manage.sh list profiles/arch-laptop
$ ./manage.sh install profiles/arch-laptop all
$ ./manage.sh deploy profiles/arch-laptop all
#+end_src

Deploying only creates symlinks back into this repository, so editing a file
here is immediately live. The =.gitignore= is an allow-list: everything is
ignored unless explicitly listed, which keeps runtime state out of the history.

Two profiles exist, =arch-laptop= and =arch-vps=, with the same modules and
packages. Anything that must differ per machine goes through a small untracked
file that the profile writes at deploy time rather than through separate copies
of the config. Those are =~/.bashrc.local=, sourced by =bashrc=, and
=~/.config/tmux/local.conf=, sourced last by =tmux.conf=; the VPS profile uses
them to turn the prompt and the tmux status bar blue so that a shell on the
server is recognizable at a glance.

* Content
*** bash

This is a fairly classic Bash setup with a few customizations here and there. It
leverages =fzf= a little bit:

  - =ff= lists files with =fd=
  - =fr= searches their contents with =ripgrep=, both hand the selection to =fo=
    which opens it in Emacs or with =rifle=.
  - =fy= installs Arch packages with a preview, =fdc= / =fdi= browse docker
    containers and images, and =M-d= is a fuzzy =cd=.

The prompt is green for a normal user and red for root. A profile can override
the color by writing =PROMPT_COLOR=<ansi code>= into =~/.bashrc.local=, which
=bashrc= sources before building =PS1=; the VPS profile sets =34= (blue). Root
stays red everywhere.

*** bin

Utility scripts that I use more or less often. Careful, some are quick hacks.
The important one is probably =clip.sh=, the single clipboard backend that tmux,
bash, i3 & co go through. =ft.sh= is the fzf tmux session picker shared by bash
(=ft=), the tmux popup (=prefix C-s=) and i3 (=Mod+Return=): Enter attaches to
the selected session or creates one named after the query, =C-o= opens a new
grouped view, =C-r= kills, =M-n= renames.

*** emacs

Everything is described in the literate configuration [[./emacs/skywhi.org][skywhi.org]]. =init.el=
tangles it into =~/.cache/emacs/=, compiles it and loads it. Emacs starts as a
server from i3, with the Org agenda on the first workspace, and every other
window is an =emacsclient=.

*** git

Commits are GPG-signed by default, whitespace errors are fixed on =apply=, the
default branch is =main=, and a handful of short aliases (=ss=, =lg=, =ob=, …)
save some typing.

*** gnupg

A conservative =gpg.conf=: strong cipher and digest preferences, long key ids
with fingerprints, minimal exports. *Disclaimer*: I am not your cryptographer,
always double-check everything according to best practices.

*** i3

A fairly standard [[https://i3wm.org/][i3]] configuration with =Mod4= as modifier, keyboard arrows or
vim-style =h= =j= =k= =l= to move focus, workspaces on the azerty number row and
more. Four scratchpads are one key away: a terminal, a Python REPL, the tmux
system monitor and newsboat. Other shortcuts launch a terminal, dmenu, an Emacs
client, the agenda, ranger, Firefox, the fzf tmux session picker, screenshots with
=scrot= and the =clipmenu= clipboard history, etc.

It uses [[https://i3wm.org/i3bar/][i3bar]] and [[https://i3wm.org/i3lock/][i3lock]].

*** irssi

A minimal [[https://irssi.org/][irssi]] configuration: identity and nick, a few sane settings, and
nothing else.

*** newsboat

My [[https://newsboat.org/][newsboat]] configuration for reading RSS feeds: automatic reloads, vim keys to
navigate, articles open in Firefox and a =v= macro sends videos to =mpv=.

*** ranger

The [[https://github.com/ranger/ranger][ranger]] file manager with a =scope.sh= that previews text, archives, images
and PDFs, a =rifle.conf= to pick openers, and a few custom commands, notably
=fzf_select= to jump anywhere with fzf.

*** tmux

An opinionated [[https://github.com/tmux/tmux][tmux]] configuration: Emacs key bindings, =prefix arrows= or
=prefix h= =j= =k= =l= to move between panes, splits that keep the current path,
mouse support, =prefix C-s= for the fzf session picker in a popup and =prefix b=
to reach a nested tmux over ssh. Every copy,
including OSC 52 from Emacs, goes through =clip.sh= into the system clipboard.
The status bar is green; =tmux.conf= ends by sourcing =~/.config/tmux/local.conf=
if it exists, so a profile can override any setting per host. The VPS profile
writes a blue bar there.

*** vimium

My [[https://github.com/philc/vimium][vimium]] settings for Firefox, mostly so that link hints use azerty home-row
letters.

*** xorg

Everything about X11. =xinitrc= loads the fonts and =Xresources=, sets the
=fr oss= and bépo layouts plus the TypeMatrix =xkb= map, starts =urxvtd=,
=unclutter=, =autocutsel= (mouse selection and clipboard kept in sync) and
=clipmenud=, then i3.

=Xresources= configures urxvt with its perl extensions and includes one of two
colour schemes, =Xlight_theme= or =Xdark_theme=, derived from Solarized. A
small =wallpapers/= collection feeds =feh= and the locker.
