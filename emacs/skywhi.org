* About
:PROPERTIES:
:CUSTOM_ID: About
:END:

This is my attempt at a self-documented Emacs configuration. It is aimed towards
programming (C, Python, Bash and more) and document writing with Org mode. I
have stolen a lot of this stuff from some very kind people, feel free to do the
same here :)

The usual disclaimer applies: note that this is a constant work-in-progress
setup, you should expect it to be quite hacky and not thoroughly tested. Always
refer to the documentation when in doubt. Now please, have at it!

Here are some setups that helped me build this one, you should check them out!

*** Lexical Binding
:PROPERTIES:
:CUSTOM_ID: Prelude-lexical
:END:

This block is tangled first so that the generated =skywhi.el= starts with the
lexical-binding cookie (Emacs ≥ 30 warns about files without it). Every block
is tangled to =$XDG_CACHE_HOME/emacs/skywhi.el= thanks to the file-level
=header-args= property at the top of this document, and =init.el=
byte-compiles the result so that it gets native-compiled too.

#+begin_src emacs-lisp
;;; skywhi.el --- Tangled from skywhi.org  -*- lexical-binding: t -*-
#+end_src

*** Emacs Server
:PROPERTIES:
:CUSTOM_ID: Prelude-server
:END:

Starting Emacs as a server allows to spawn instantly multiple clients sharing
the same buffers without the need to reload the configuration file every time. I
then use ~alias emc='emacsclient -c '~ in my =.bashrc= file to start a new Emacs
client in the terminal and connect to the server.

#+begin_src emacs-lisp
(require 'server)
(unless (server-running-p) (server-start))
#+end_src

*** User Files
:PROPERTIES:
:CUSTOM_ID: Prelude-files
:END:

Define the files and directories that will be used across the configuration.
Everything that is *state* (packages, caches, history, backups, =custom.el=)
lives under =skw/d-cache= (=$XDG_CACHE_HOME/emacs=, i.e. =~/.cache/emacs= by
default) so that the dotfiles directory only ever contains the tracked
configuration. This keeps =git status= clean and lets =.gitignore= stay small.

The variables are declared with =defvar= (and wrapped in =eval-and-compile=)
so that they also exist when =init.el= byte-compiles this file: =use-package=
installs =:ensure= packages at expansion time and needs =package-user-dir= to
already point at the cache. =init.el= declares =skw/d-cache= the same way
(it needs it before this file exists); =defvar= makes the two definitions
harmless duplicates.

#+begin_src emacs-lisp
(eval-and-compile
  (defvar skw/d-cache
    (expand-file-name "emacs/" (or (getenv "XDG_CACHE_HOME") "~/.cache"))
    "Directory holding every piece of Emacs state (packages, history, …).")
  (defvar skw/d-base     user-emacs-directory)
  (defvar skw/f-config   (concat skw/d-base "skywhi.org"))
  (defvar skw/d-elisp    (concat skw/d-base "my_elisp/"))
  (defvar skw/d-snippets (concat skw/d-base "my_snippets/"))
  (defvar skw/f-custom   (concat skw/d-cache "custom.el"))
  (defvar skw/d-savedir  (concat skw/d-cache "saves/"))
  (defvar skw/f-savehist (concat skw/d-cache "savehist"))

  (make-directory skw/d-cache t)
  (make-directory skw/d-savedir t))
#+end_src

Redirect the remaining built-in state files there as well. Packages installed
via =package.el= go to =skw/d-cache/elpa= (must be set before
=package-initialize=), native-compiled code to =skw/d-cache/eln-cache=.

#+begin_src emacs-lisp
(eval-and-compile
  (setq package-user-dir (concat skw/d-cache "elpa/")))

(setq auto-save-list-file-prefix (concat skw/d-cache "auto-save-list/.saves-")
      bookmark-default-file      (concat skw/d-cache "bookmarks")
      save-place-file            (concat skw/d-cache "places")
      tramp-persistency-file-name (concat skw/d-cache "tramp")
      project-list-file          (concat skw/d-cache "projects")
      transient-history-file     (concat skw/d-cache "transient-history.el")
      url-configuration-directory (concat skw/d-cache "url/"))

(when (fboundp 'startup-redirect-eln-cache)
  (startup-redirect-eln-cache (concat skw/d-cache "eln-cache/")))
#+end_src

Also add custom Emacs Lisp files to =load-path= while we are at it.

#+begin_src emacs-lisp
(eval-and-compile
  (when (file-readable-p skw/d-elisp)
    (add-to-list 'load-path skw/d-elisp)))
#+end_src

*** Package Initialization
:PROPERTIES:
:CUSTOM_ID: Prelude-package
:END:

I get my packages from [[https://elpa.gnu.org/][GNU ELPA]], [[https://elpa.nongnu.org/][NonGNU ELPA]] (both configured by default
since Emacs 28, =org-contrib= lives on NonGNU) and [[https://melpa.org/packages/][MELPA]]. The old
=orgmode.org/elpa= archive has been frozen since 2022 and is not used anymore.
[[https://github.com/jwiegley/use-package][use-package]] is built into Emacs (≥ 29) and takes care of installing the
remaining packages (with the =:ensure t= flag) for us.

The whole block is evaluated at compile time as well (see above).

#+begin_src emacs-lisp
(eval-and-compile
  (require 'package)

  (add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/"))
  (add-to-list 'package-archives '("nongnu" . "https://elpa.nongnu.org/nongnu/"))

  ;; Speed-up start-up by loading a single pre-computed autoloads file
  (setq package-quickstart t
        package-quickstart-file (concat skw/d-cache "package-quickstart.el"))

  (unless package--initialized
    (package-initialize))
  (unless package-archive-contents
    (package-refresh-contents))

  (require 'use-package)
  ;; Packages are loaded eagerly unless a block says otherwise (:defer, :hook,
  ;; :bind, :commands). Explicit is better than implicit here.
  (setq use-package-always-defer nil))
#+end_src

Let's always compile packages thanks to =auto-compile= to make sure that Emacs
never loads outdated code.

#+begin_src emacs-lisp
(use-package auto-compile
  :ensure t
  :config
  (setq load-prefer-newer t)
  (auto-compile-on-load-mode))
#+end_src

Warnings are kept at their default level: hiding them is how a broken
=backup-directory-alist= went unnoticed for years. Only the noisy
=cl-functions= byte-compiler warning is muted. Wrapped in =eval-and-compile=
so that it also applies while =init.el= byte-compiles this very file.

#+begin_src emacs-lisp
(eval-and-compile
  (setq byte-compile-warnings '(not cl-functions)))
#+end_src

Emacs ≥ 30 also warns about every loaded file lacking a =lexical-binding=
cookie on its first line. The per-machine overlays tangled by =init.el=
(=~/org/perso/conf.org=, …) do not carry one, so that specific warning is
silenced (not even logged to =*Warnings*=) instead of being fixed in every
overlay. It is the only entry of the =files= warning group, hence the whole
group is muted.

#+begin_src emacs-lisp
(add-to-list 'warning-suppress-log-types '(files))
#+end_src

***** Default modes and hooks

These are the built-in modes and hooks that I like to have enabled by
default.

#+begin_src emacs-lisp
;; Default built-in modes
(setq-default major-mode 'text-mode)
(auto-compression-mode t)        ;; Handle compressed files
(file-name-shadow-mode t)        ;; Better minibuffer filenames
(save-place-mode t)              ;; Remember point location
(global-auto-revert-mode t)      ;; Automagically refresh buffers
(global-subword-mode t)          ;; Treat camelCase as 2 words
(global-font-lock-mode t)        ;; Syntax highlighting
(global-prettify-symbols-mode t) ;; Prettify things if possible

;; Hooks: clickable urls/emails in text, and only in comments/strings in code
(add-hook 'text-mode-hook 'goto-address-mode)
(add-hook 'prog-mode-hook 'goto-address-prog-mode)
(add-hook 'text-mode-hook 'turn-on-auto-fill)      ;; Automatically wrap text
#+end_src

Trailing whitespace is removed on save, but only on the lines that were
actually edited thanks to [[https://github.com/lewang/ws-butler][ws-butler]]. A global =whitespace-cleanup= would rewrite
every file we touch — including other people's repositories and tab-indented
Makefiles — which makes for noisy diffs.

#+begin_src emacs-lisp
(use-package ws-butler
  :ensure t
  :diminish ws-butler-mode
  :hook ((prog-mode text-mode conf-mode) . ws-butler-mode))
#+end_src

***** Scrolling

Smoother scrolling options and keybindings to scroll unfocused windows.
=scroll-conservatively= above 100 makes Emacs scroll line by line instead of
recentering; =scroll-step= is left alone as it interacts badly with
=scroll-margin=.

#+begin_src emacs-lisp
(setq scroll-margin 5
      scroll-conservatively 101
      scroll-preserve-screen-position 1)

(defun skw/scroll-other-window-up ()
  "Scroll the other window up by two lines."
  (interactive)
  (scroll-other-window 2))

(defun skw/scroll-other-window-down ()
  "Scroll the other window down by two lines."
  (interactive)
  (scroll-other-window-down 2))

(global-set-key (kbd "C-x v <up>")   'skw/scroll-other-window-down)
(global-set-key (kbd "C-x v <down>") 'skw/scroll-other-window-up)
(global-set-key (kbd "C-v") 'scroll-down)
(global-set-key (kbd "M-n") 'scroll-up)
#+end_src

***** Themes

A safer =load-theme=: =skw/disable-all-themes= disables every enabled theme
and is advised before =load-theme= so that themes never stack. It is also a
command (=C-c t d=) to go back to stock Emacs colours; the =&rest _= swallows
the arguments =load-theme= passes when it runs as advice.

#+begin_src emacs-lisp
(defun skw/disable-all-themes (&rest _)
  "Disable every enabled custom theme."
  (interactive)
  (mapc #'disable-theme custom-enabled-themes))

(advice-add 'load-theme :before #'skw/disable-all-themes)
#+end_src

Some themes from [[https://protesilaos.com/emacs/ef-themes][ef-themes]] by [[https://protesilaos.com/][Protesilaos Stavrou]] that I like. The package
ships its own commands: =ef-themes-toggle= (=C-c t t=) flips between the two
themes of =ef-themes-to-toggle= and =ef-themes-select= (=C-c t s=) prompts for
any of them; both disable the previous theme first. No theme is loaded at
start-up: Emacs starts with its stock colours and =C-c t t= enables =ef-dark=
(then flips to =ef-bio=). The colourful mode-line of old came from
=smart-mode-line='s own =light= theme, which is gone.

#+begin_src emacs-lisp
(use-package ef-themes
  :ensure t
  :bind (("C-c t t" . ef-themes-toggle)
         ("C-c t s" . ef-themes-select)
         ("C-c t d" . skw/disable-all-themes))
  :custom
  (ef-themes-to-toggle '(ef-dark ef-bio)))
#+end_src

***** Completion: =vertico= + =orderless= + =consult= + =marginalia= + =embark=

Minibuffer completion is provided by a set of small, composable packages that
all build on the standard Emacs completion API (=completing-read=) instead of
reimplementing it:

- [[https://github.com/minad/vertico][vertico]] displays candidates vertically in the minibuffer,
- [[https://github.com/oantolin/orderless][orderless]] matches space-separated patterns in any order (=foo bar= matches
  =bar-foo=; a trailing =~= makes a component fuzzy, a leading === literal),
- [[https://github.com/minad/consult][consult]] provides the "search and navigate" commands (buffers, lines,
  ripgrep, imenu, yank-pop, …) with live preview,
- [[https://github.com/minad/marginalia][marginalia]] annotates candidates (docstrings, file sizes, …),
- [[https://github.com/oantolin/embark][embark]] offers context actions on the candidate at point (=C-.=),
- =savehist= (built in) remembers recent choices so they sort first.

The keybindings intentionally mirror the previous =ivy=/=counsel=/=swiper=
setup: =C-s s= search in buffer, =C-s r= ripgrep, =C-s z= find files,
=C-x b= buffers, =C-M-l= imenu, =M-y= yank-pop, =M-x= / =C-c m= commands.

***** Escape / unescape quotes

#+begin_src emacs-lisp
(defun skw/escape-quotes (begin end)
  "Backslash-escape every double quote between BEGIN and END."
  (interactive
   (if (use-region-p)
       (list (region-beginning) (region-end))
     (list (line-beginning-position) (line-end-position))))
  (save-excursion
    (save-restriction
      (narrow-to-region begin end)
      (goto-char (point-min))
      (while (search-forward "\"" nil t)
        (replace-match "\\\"" t t))))
  (message "Escaped quotes"))

      (narrow-to-region begin end)
      (goto-char (point-min))

***** =eglot= (LSP) and =flymake=

[[https://www.gnu.org/software/emacs/manual/html_node/eglot/][eglot]] is the built-in LSP client (Emacs ≥ 29): completion (through
=company-capf=), diagnostics (through the built-in =flymake=), rename, xref…
It is started automatically in C, Python and shell buffers (both the classic
and the tree-sitter major modes: the =-ts-= modes do *not* run the classic
modes' hooks, so both are listed and the server lookup uses =derived-mode-p=),
but only when a language server is actually installed: the servers come from
the =clang=, =pyright= and =bash-language-server= Arch packages (see the
profiles). Buffers managed by =eglot= are formatted by the server on save,
which replaces =py-autopep8=; the hook is removed again when =eglot= is shut
down (=eglot-managed-mode-hook= runs on disable too). Toggle =flymake-mode= with =<f6>=; =M-n= / =M-p= are not
touched, use =M-g n= / =M-g p= (=next-error=) to jump between diagnostics.

#+begin_src emacs-lisp
(defvar skw/eglot-servers
  '(((c-mode c-ts-mode c++-mode c++-ts-mode) . "clangd")
    ((python-mode python-ts-mode)            . "pyright-langserver")
    ((sh-mode bash-ts-mode)                  . "bash-language-server"))
  "Alist of (MAJOR-MODES . EXECUTABLE) for which `eglot' is started.")

(defun skw/eglot-ensure-if-server ()
  "Start `eglot' if a server for the current major mode is installed."
  (let ((server (cdr (seq-find (lambda (entry)
                                 (apply #'derived-mode-p (car entry)))
                               skw/eglot-servers))))
    (when (and server (executable-find server))
      (eglot-ensure))))

(defun skw/eglot-format-on-save ()
  "Format the buffer with the language server before saving.
Installed when `eglot' starts managing the buffer, removed when it stops."
  (if (eglot-managed-p)
      (add-hook 'before-save-hook #'eglot-format-buffer -10 t)
    (remove-hook 'before-save-hook #'eglot-format-buffer t)))

(use-package eglot
  :ensure nil ;; built-in
  :hook ((c-mode c-ts-mode c++-mode c++-ts-mode
          python-mode python-ts-mode sh-mode bash-ts-mode)
         . skw/eglot-ensure-if-server)
  :hook (eglot-managed-mode . skw/eglot-format-on-save)
  :bind (:map eglot-mode-map
              ("C-c e r" . eglot-rename)
              ("C-c e a" . eglot-code-actions)
              ("C-c e f" . eglot-format))
  :custom
  (eglot-autoshutdown t))

(use-package flymake
  :ensure nil ;; built-in
  :diminish flymake-mode "check"
  :hook (emacs-lisp-mode . flymake-mode)
  :bind (("<f6>" . flymake-mode)
         :map flymake-mode-map
         ("C-c e l" . flymake-show-buffer-diagnostics)))
#+end_src

Emacs ≥ 29 ships tree-sitter major modes. Files are remapped to them only when
